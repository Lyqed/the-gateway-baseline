# Design brief

This site uses the machined-atrium design system: white curved architecture,
brushed steel, hard skylight geometry, and hand-drawn annotations that break
the grid at chosen moments. Light-first by conviction; the tokens, the three
type voices (Space Grotesk, IBM Plex Mono, Shantell Sans for hand
annotations), and the vocabulary marks (the ring, skylight bands, the
perforated rail, hand strokes) are defined in `src/app/globals.css` and the
components under `src/components/`.

The site states one thing: the cost-attribution requirements for AI traffic,
centered on why an authoritative figure (the dollars the provider actually
billed) beats an estimate, and on the trust choice a team makes.

The full art-direction document that this system derives from is kept with the
gateway project it was written alongside, not in this repository.
